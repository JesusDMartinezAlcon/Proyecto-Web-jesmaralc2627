# Proyecto-Web-jesmaralc2627

🌐 **Pequeño proyecto de página web para verificar el funcionamiento de GitHub.**

## Descripción

Este proyecto tiene como objetivo servir de prueba para practicar el uso de **Git** y **GitHub**, comprobando el correcto funcionamiento del control de versiones, los commits y la sincronización con repositorios remotos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

---

✍️ Proyecto desarrollado con fines educativos.
